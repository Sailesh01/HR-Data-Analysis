# 🧑‍💼 HR Data Analysis Dashboard

Multi-platform dashboards built using Excel, Power BI, Tableau, and SQL to track and analyze key HR metrics.

This project focuses on workforce data — including employee count, attrition trends, age distribution, and job satisfaction — to support data-driven HR decisions. KPIs and visualizations were designed to highlight departmental turnover, gender-based attrition, and demographic insights.

📊 Dashboards cover:
- Employee Count & Attrition Overview
- Attrition by Gender & Department
- Workforce Demographics & Job Satisfaction

🔍 Tools used: Excel, Power BI, Tableau, SQL
